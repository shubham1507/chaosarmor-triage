# GO-007 - Model an incident snapshot

## What changed

Grouped the service name, failed-request count, and recent deployment
status in `IncidentSnapshot`. The CLI initializes the struct with a
keyed literal and calls its `print` method.

## Why

A named record gives future JSON and HTTP code a concrete type for the
snapshot fields.

## Go concepts

- A struct groups related fields with different types.
- A keyed literal initializes fields by name.
- A value receiver gives the method a copy of the snapshot.
- The fields are exported so a future JSON encoder can read them.

## Files changed

- `main.go` constructs the snapshot and calls its method.
- `snapshot.go` defines the struct and its display method.
- `docs/development/GO-007.md` records the change and verification.
- `docs/development/README.md` links this entry.
