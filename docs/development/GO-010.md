# GO-010 - Export the incident snapshot as JSON

## What changed

Added `-snapshot-json` to write the basic incident snapshot as one JSON
object. The keys are `service`, `failed_requests`, and `recent_deployment`.
Zero and false are included. The default text report still shows its
existing assessment and history when those inputs are supplied.

## Why

Scripts can read snapshot fields directly from JSON. The same field
names can be reused by a future API.

## Go concepts

- `encoding/json` encodes exported struct fields.
- Struct tags define the JSON key names.
- `json.NewEncoder` writes to an `io.Writer` and returns encoding errors.

## Files changed

- `main.go` adds the JSON output flag and encoding branch.
- `internal/snapshot/snapshot.go` defines the JSON field names.
- `docs/development/GO-010.md` records the change.
- `docs/development/README.md` links this entry.

## Verify

- `go test ./...` and `go vet ./...` succeed.
- `go run . -service checkout -failed-requests 12 -deployed -snapshot-json`
  emits a single JSON object containing checkout, 12, and true.
- `go run . -snapshot-json` includes `failed_requests: 0` and
  `recent_deployment: false` in the JSON output.
- The GO-009 sample produces identical text without `-snapshot-json`.
