# GO-009 - Extract the incident snapshot package

## What changed

Moved `IncidentSnapshot`, its `WriteTo` method, and the output test to
`internal/snapshot`. The CLI imports the package using the existing
module path and calls `WriteTo` on the exported type.

## Why

The CLI and a future HTTP handler can share the snapshot model and text
output while the package remains internal to the project.

## Go concepts

- `go.mod` defines the module path used by local imports.
- `main` and `snapshot` are packages within the same module.
- Uppercase identifiers are exported across package boundaries.
- Package and declaration comments appear in `go doc`.

## Files changed

- `main.go` imports and uses the snapshot package.
- `internal/snapshot/snapshot.go` contains the moved model and method.
- `internal/snapshot/snapshot_test.go` contains the moved output test.
- `docs/development/GO-009.md` records the change and verification.
- `docs/development/README.md` links this entry.

## Verify

- `go list ./...` lists the CLI and snapshot packages.
- `go doc ./internal/snapshot IncidentSnapshot` shows the exported type.
- `go test ./...`, `go vet ./...`, and `go build ./...` succeed.
- The checkout sample prints the same snapshot, severity, and history as GO-008.
