# GO-005 - Separate trend calculation from CLI output

## What changed

Extracted `summarizeFailureTrends` to return transition counts without
printing. `forEachTransition` visits adjacent windows in order and invokes
a callback for each pair. The callback closes over the counts map.
`printFailureTrends` uses the result and prints the existing report.

## Why

The same trend calculation can be reused by a future HTTP handler or
incident summary without parsing CLI output.

## Go concepts

- Typed function parameters and return values.
- A higher-order function that accepts a callback.
- An anonymous function that captures a map from its enclosing scope.
- The existing parser still demonstrates a value and error return.

## Files changed

- `history.go` extracts the reusable trend functions.
- `docs/development/GO-005.md` records the change and verification.
