# GO-001 - Initialize the Go triage CLI

## What changed

Initialized the Git repository and Go module. Added an executable
`main` package that prints a startup message and a README with local
run instructions.

## Why

A runnable CLI establishes the entry point for collecting and reviewing
deployment and health-check evidence.

## Go concepts

- `go.mod` declares the module path.
- `package main` identifies an executable package.
- `func main()` is the program entry point.
- `fmt.Println` writes a line to standard output.

## Files changed

- `go.mod` defines the module.
- `main.go` contains the CLI entry point.
- `README.md` describes the project and how to run it.

## Verify at GO-001

Run `go run .` and expect `ChaosArmor Triage is ready.`.
Run `go vet ./...` and expect it to complete successfully.
