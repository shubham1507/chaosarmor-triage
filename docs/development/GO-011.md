# GO-011 - Read and sort an incident timeline from a file

## What changed

`-timeline-file` reads a headerless two-column CSV of RFC 3339 timestamps
and event messages. It prints events in UTC, keeps input order for ties,
and prints a SHA-256 digest of the original file bytes. Malformed input
produces a diagnostic with record context and a nonzero exit.

## Why

An on-call engineer can put deployment and health-check events in order
and identify the source file used to build the timeline.

## Files changed

- `main.go` adds the CLI flag and selects timeline mode.
- `timeline.go` reads, validates, sorts, hashes, and writes the timeline.
- `timeline_test.go` covers ordering, ties, and malformed timestamps.
- `docs/development/GO-011.md` records the change and verification.
- `docs/development/README.md` links this entry.

## Verify

- Run `go test ./...` and `go vet ./...`.
- Run `go run . -timeline-file events.csv` with out-of-order records.
  Expect the earliest event first and a SHA-256 digest on the final line.
- Compare the digest with `Get-FileHash -Algorithm SHA256 events.csv`.
- Compare the existing text and JSON snapshot outputs with GO-010.
