# GO-008 - Write incident snapshots through an interface

## What changed

`IncidentSnapshot.WriteTo` writes the snapshot to an `io.Writer` and
returns the byte count and any write error. The CLI passes `os.Stdout`.
A test calls the method through `io.WriterTo` and writes to a buffer.

## Why

The same snapshot can be written to different destinations without
changing how it is formatted.

## Go concepts

- A value receiver lets both the struct and a pointer to it satisfy
  `io.WriterTo`.
- The method signature satisfies the interface implicitly.
- `io.Writer` lets the caller choose the output destination.

## Files changed

- `main.go` writes the snapshot to standard output and handles write errors.
- `snapshot.go` implements `io.WriterTo`.
- `snapshot_test.go` verifies the buffer contents and byte count.
- `docs/development/GO-008.md` records the change.
- `docs/development/README.md` links this entry.
